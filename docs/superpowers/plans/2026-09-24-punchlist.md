### Specs (single source for the worker prompts; contract §2 has the boundary rules)
- **Shared:** every test run sets `TEST_DB` to your own name (W1 `plantcare_test_w1`, W2 `plantcare_test_w2`, W3 `plantcare_test_w3`, W4 `plantcare_test_w4`); the dev DB `plantcare` is never written by tests. Existing error kinds only; `eval/run.py` retries `cli_error` and `timeout`. Each item is its own commit on `main`, message ending with the co-author line. No edits outside your fence; `rag/retrieve.py`, `rag/pipeline.py`, `rag/generate.py`, `prompts/*`, `corpus/*`, `eval/questions.jsonl`, `eval/results/*` are nobody's this round.
- **P1 (W1):** `shutil.which("claude")` is None → `LLMError("cli_error", "claude CLI not found on PATH", 0)`; stdout without a parseable JSON object (including `JSONDecodeError`) → `schema_invalid`; `is_error` or non-zero exit → `cli_error` whose detail joins the payload `subtype`, `exit <code>`, and the stderr tail, 500 chars max, never empty; api backend: client built with `max_retries=0`; `anthropic.APIConnectionError` (covers `APITimeoutError`) retried by the existing loop, then `timeout` for timeouts and `cli_error` otherwise; missing text block or non-JSON text → `schema_invalid`. Tests fake `subprocess.run`, `shutil.which`, and `anthropic.Anthropic`; no network.
- **P2 (W2):** `psycopg_pool.ConnectionPool` (new dep `psycopg-pool`), `configure=db.register`, `check=ConnectionPool.check_connection`, `max_size = MAX_INFLIGHT + 2`, opened in lifespan and closed on shutdown; `create_app(conn=...)` keeps working for tests (a given connection is used as-is). `MAX_INFLIGHT` env (default 4) bounds concurrent `/ask` generations with a non-blocking `threading.BoundedSemaphore`; when full → 503, `Retry-After: 5`, body `{"detail": "busy"}`. `GET /healthz` → `{"status": "ok"}` always (async, touches nothing). `GET /readyz` → 200 `{"status": "ready", "chunks": n}` when the DB answers `SELECT count(*) FROM chunks` > 0 and the embedder is loaded, else 503 `{"status": "not ready", "failed": [...]}`. Request id: `X-Request-ID` if it matches `^[A-Za-z0-9._-]{1,64}$`, else uuid4 hex; echoed on every response. One JSON line per `/ask` on logger `rag.api` (INFO): `request_id, status, total_ms, k, mode, decompose, n_queries, chunk_ids, citations, refused, error_kind, model, usage, question_chars, question_sha` (sha256 hex, 12 chars); never the question text. `API_KEY` env (optional): set → `/ask` needs `Authorization: Bearer <key>` (`hmac.compare_digest`), 401 otherwise, health routes stay open; unset → one startup warning. New env keys go through `rag/config.py` `_KEYS` (`API_KEY`, `MAX_INFLIGHT`) and `.env.example` gains them commented, no values.
- **P3 (W3):** `db/init/002_embed_model.sql`: `ALTER TABLE chunks ADD COLUMN IF NOT EXISTS embed_model text;` backfill `'BAAI/bge-base-en-v1.5'` where NULL; `SET NOT NULL`; idempotent.
